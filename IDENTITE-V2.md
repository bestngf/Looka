# Identité NGF v2 (refonte)
Look clair et élégant (ivoire, filets dorés, motif africain en décor), mode sombre doux qui suit le téléphone.
Bouton « Apparence » (dans la barre du haut, ou dans le menu pour LOKAA) : thème prêt, couleur libre, ambiance, motif, arrondi, taille du texte. Les choix restent sur le téléphone.
Fichiers : ngf-theme.js (réglages), la feuille de style de l’identité, la barre de marque.
Pour changer la couleur de départ de l’app : attribut data-ngf-domaine sur <html> (Resto, Commerce, Marketplace, Location, Formation, Don).
